Text → Image (FLUX.1 Krea [dev])

Text/Image → Video+Audio (MiniMax-H3)

Default backend runs H3 100% locally through a ComfyUI server on your machine/GPU (no cloud API call) - install ComfyUI + the model files first (see README/Settings). MiniMax's hosted API is available as a non-local fallback if you don't have a GPU set up. (Local diffusers execution for H3 doesn't exist in any public diffusers release yet.)

ComfyUI (used by comfyui backend - genuinely local, runs on your GPU)

Install ComfyUI, download the model files listed on Comfy-Org/MiniMax-H3 into ComfyUI's models folders, then start ComfyUI (python main.py) before generating video.

MiniMax API (used by API backend)

API key is read from the MINIMAX_API_KEY environment variable, not stored here. Sign up and get a key at platform.minimax.io.

Hugging Face account (required for Krea + H3 weights)

Both models are gated. Steps (one-time, needs your own free account - an agent can't do this for you): 1) Sign in at huggingface.co. 2) Click "Agree and access repository" on FLUX.1-Krea-dev and MiniMax-H3. 3) Create a read token at huggingface.co/settings/tokens and paste it below.
